# BrisaShop · Documentação

Documentação de arquitetura do [BrisaShop](https://github.com/sidartaoss/brisashop), loja online fictícia de uma varejista de moda. Fica em repositório próprio e é mantida como código (Markdown e diagramas em texto), para evoluir junto com os serviços: design estratégico (subdomínios, contextos delimitados e mapa de contextos), arquitetura de microsserviços, modelos de domínio e registros de decisão (ADRs).
